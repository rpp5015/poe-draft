# POE Auction Draft Board

Live auction draft board for the Powerhouse of Excellence fantasy league.
One operator runs the draft on the big screen; the league follows along read-only.

**Live app:** https://rpp5015.github.io/poe-draft/

- Real-time sync via Firebase Firestore (per-pick documents)
- Shareable read-only spectator link
- Fixed nomination order, keeper support, ⅔-value min bid, Excel export

Single self-contained `index.html` — no build step.
